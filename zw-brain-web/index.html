优先验证四件事
  • 模板复用：R1 是否默认先看到法人模板，而不是新建整表。
  • 差异补录：基层是否只补现场缺口，而不是重填基础字段。
  • 回流沉淀：汇总后的高频差异字段是否进入模板治理视图。
  • 治理投影：P6 与 K12 看到的是否是减负结果、异常责任链和证据。
关键守卫
任何“批准 / 汇总确认 / 回流共享 / 能力上线”都必须保留人工确认动作。
指挥大屏是独立只读投影；主大脑异常时进入快照模式，而不是接管办理态。
被退回、驳回或熔断时，要在链路上留下清晰阻断语义与审计证据。
