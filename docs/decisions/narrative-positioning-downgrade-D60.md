# D60 · 对外叙事定位降权（数据共享网关→平台 + 飞轮倍速降脚注）

**类别**：对外叙事/定位，D28 GATE · **签字**：薛娇（产品研发负责人）2026-06-15 · `decision_only`
**签字账本**：`.testing/signoff/narrative-positioning-downgrade.signoff.yaml`

## 背景

乔布斯上帝视角重审残刀 F：

- 「数据共享网关」是管道工口吻、客户听不出价值；全仓 grep 仅 **3 处内部命中**（`architecture.md` §1.1 ×2 + `AGENT.yaml`），**零 webui/标书/用户可见面**。
- 飞轮 4×/16×/48× 倍速文档**已诚实标「预估/目标」**、velocity 脚本**已自陈「第 0 圈」**，但 0 客户、velocity 真数据=0 时仍把推算倍数摆在叙事高位（「砍夸大」本身是半假象——账本没撒谎，只是权重过高）。

## 裁决

1. 对外产品身份 "数据共享网关" → **"数据共享平台"**（`architecture.md` §1.1 两处）。
2. 架构基线 §1.1 顶部补**客户面体验承诺**一句话：**「要数据，不用再跑窗口、不用再问我是哪个角色、拿到就能调用。」**「平台」是内部品类口径，用户感知是这句承诺。
3. 飞轮 §7.1 倍速表加**「样本量=0、未验证」警示**：除 N0 baseline 实测外全为预估/目标，0 客户期降为内部规划锚点，**禁作对外卖点 / 产品心跳**。
4. `AGENT.yaml` 搜索助手口径对齐功能面「P2 资源发现页」。

## 影响

纯文档、对运行产品**零行为影响**。改的是 `docs/approved/` 设计基线措辞，故须负责人 sign-off（本条即是）。`scripts/flywheel_velocity_report.sh` 已自陈「第 0 圈/首客户尚未上线」、`velocity-history.md` 落第一行真数据前所有加速曲线标「未验证」，本期不改脚本。
