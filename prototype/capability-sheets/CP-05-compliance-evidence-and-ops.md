# CP-05｜Compliance, Evidence & Ops

## 1. 业务目标与边界

**目标**：让平台管理员能从异议、告警、交付异常或审计事件出发，快速找到原始证据、当前结论和下一步处置建议，同时始终保留可回放、可追责的事实链。

**解决的 Job**：
- 快速定位一条事件背后的审计与责任链
- 把告警、工单、知识建议和调查结论串起来
- 让领导大屏读取可信的只读事实和态势投影

**明确不做**：
- 不让 AI 覆盖原始证据
- 不把合规面改造成只剩摘要卡片的展示页
- 不把调查与处置逻辑迁移成独立平台产品

## 2. 覆盖的主旅程环节与页面

- 主旅程：S7 / S8 / S9
- 页面：P6 合规与运营、K12 指挥中心大屏
- 定位：合规与运营支撑能力

## 3. 归属判定 / Ownership boundary

CP-05 以平台内建为主。证据链事实源、调查回放和大屏读侧投影直接关系到“什么是真相”和“什么可以被追责”，不能外包主写权。即使没有摘要、排序或知识建议，管理员仍应能直接查看原始证据、责任链、调查时间线和只读投影。

### 3.1 平台内建能力
- `audit.replay-evidence-chain`
- `compliance.investigate-case`
- `dashboard.project-read-model`
- 原始证据查看、调查回放、责任链展示与大屏只读投影

### 3.2 外部 ANP 可建设的辅助能力
- `ops.summarize-alert-and-ticket`
- `knowledge.recommend-next-action`
- 告警关联与知识串联建议

### 3.3 明确禁止外部包拥有的范围
- 不得覆盖或改写原始 audit event
- 不得替平台写入最终调查结论
- 不得让大屏直接消费未经平台裁剪的敏感证据细节
- 不得让调查与证据回放依赖外部摘要能力是否在线

## 4. 统一 Capability 契约要求

### 4.1 输入 / 输出要点
- 输入：事件标识、异议标识、告警标识、任务标识、操作者身份
- 输出：审计事件序列、证据引用、工单状态、调查摘要、责任链、下一动作建议、大屏投影数据

### 4.2 Side effects 与边界
- 证据回放、调查摘要、大屏投影为 `read-mostly`
- 某些治理处置动作可为 `governed-actions`，但必须保留确认边界
- AI 只能总结与排序，不得替代原始 audit event 或最终裁定

### 4.3 ACL / tenant / audit
- 合规证据访问受严格权限控制
- 所有查看、调查、处置动作需满足审计要求
- 大屏消费的是脱敏或汇总投影，不应直接泄露不必要细节

### 4.4 回执与外部依赖
- 必须支持审计回放与证据链引用
- 可依赖工单系统、知识库、区块链锚点或监控底座
- 外部依赖应以引用与适配形式出现，不在包内复造
- 即使没有外部摘要与知识建议，平台仍需保留原始证据查看、调查回放与读侧投影的 baseline 路径

## 5. 五消费面映射

- **WebUI**：P6 展示双栏调查台、原始证据、调查摘要和告警-工单-知识联动；K12 读取只读态势投影
- **REST**：暴露审计回放、调查查询、处置辅助和看板投影接口
- **CLI**：支持审计追踪、告警工单串联查询和导出
- **MCP**：暴露为审计回放、调查辅助、知识建议类 tool / resource
- **A2A**：暴露为 agent 可消费的证据查询与调查辅助 action

要求：所有消费面都必须回指同一 audit 与 evidence 事实源，不允许各自维护不同版本的“真相”。

## 6. ANP 外部建设要求

- 适合外部建设的原因：证据摘要、告警关联、知识建议和读侧投影生成适合独立能力化
- 与主仓边界：主仓保留合规边界、页面展示和权限控制；外部包只提供统一契约下的摘要、串联和投影能力
- 回注册前需准备：manifest、证据与投影 schema、ACL 说明、脱敏策略、审计声明、知识建议来源说明

## 7. 负面流与验收口径

### 7.1 负面流
- 原始证据缺失或访问受限时，系统必须显式说明证据边界，不得用 AI 摘要替代
- 告警与工单关联失败时，系统必须保持可追踪中间态，而不是强行给出完整结论

### 7.2 设计验收标准
- 原始审计证据始终完整可见，摘要只是帮助阅读
- 告警、工单、知识建议链路逻辑清楚可信
- 即使外部辅助失效，调查、证据回放与大屏读侧投影仍可独立成立
- 大屏使用的态势投影能回指合规事实源，而不是独立生长

### 7.3 回注册核对项
- 是否明确 evidence source 与脱敏边界
- 是否保证大屏只读消费，不写主状态
- 是否保证 AI 摘要不会覆盖原始证据链
