中国政府政务网站 / 平台 WebUI 风格调研 — 四套推荐 UI Spec审核稿 · 单页对比

依据公开政策附件与行业通行做法归纳：国务院办公厅《政府网站发展指引》（国办发〔2017〕47号）附件「网页设计规范」；集约化平台建设实践中常见的栏目 / 频道 / 图标约定；地方标准（如地方政府网站集约化平台网页设计相关标准）中与界面一致性相关的条款思路。 下列四套并非官方模板，而是在合规边界内可落地的差异化方向，便于产品与视觉在未定稿前对齐。

  • 共性约束（政策侧高频要求）：整体简洁统一；主色 1 种 + 辅色搭配，全站色相一般不超过 3 种；典型三区结构（头部标识区 / 中部内容区 / 底部功能区）；频道不宜过多（指引中常见表述为约 5～8 个）；图标多用扁平风格；避免不必要的悬浮、闪烁干扰；页面需兼顾常用分辨率与加载体验。
  • 组件与版式惯例：头部突出站点名称与检索入口；中部遵循从左到右、从上到下的阅读习惯；底部通常包含党政机关网站标识、「我为政府网站找错」入口、网站标识码、主办单位与联系方式、ICP 与公安备案、站点地图等要素（以各单位最新要求为准）。

选型更新：zw-brain 公共服务 / 办事类 WebUI 已选用 Spec B · 一网通办服务。细化稿（色板、组件、版式、合规对照、参考组合）见 spec/ui/gov-ui-spec-b-service.html。

定位 最贴近「门户 / 部门站」正文气质，强调栏目与政策可读性。 突出办事检索与服务聚合，典型政务服务网心智。 高对比、大字号、少干扰，适合长者与基层窗口引用。 指挥舱 / 运行态势只读展示，与公共服务门户刻意区分。
主色建议 政务蓝 #0C4DA2；点缀红 #C8161D（用于标题条 / 警示）。 服务蓝 #006BE6 + 辅助青绿 #009688（仍控制在三色体系内）。 纸米色底 #FAF8F3 + 深褐字；强调色单一金棕 #C9A227。 深蓝黑底 #060D18；前景冰蓝灰字；强调鎏金 #E8C872。
字体与层级 标题 16–18px，正文 14px，行距约 1.6；同一栏目模板统一。 搜索框与按钮强化；列表标题略大于正文。 正文基础 ≥18px，可一键放大至 22px；按钮触控区 ≥44px。 标题压缩；数字 KPI 强化（等宽数字）；说明削弱。
布局骨架 顶栏 Logo + 搜索 → 横向频道 → 左右分栏要闻 / 信息公开。 顶部大检索 → 服务图标矩阵 → 分区 Tab + 列表。 宽留白单栏为主；模块卡片少而清晰。 顶栏标题 → 多宫格指标 → 底部滚动次要说明。
组件倾向 面包屑、分页、政策文件列表、标签 meta 思想体现在页面信息架构。 96×96 量级扁平服务图标、办事日历 / 进度样式占位。 少图标多文字；焦点框清晰的按钮；避免细小链接。 迷你趋势底纹、阈值色（沿用主色体系内对比）。
动效与干扰 静态优先；禁用闪烁广告位；悬浮层默认关闭。 检索聚焦轻微阴影；避免循环动画。 禁用自动轮播；用户主动切换。 允许低频刷新指示；禁止炫光大面积闪烁。
适用产品 政府门户网站、部门子站、政务公开子系统。 一体化政务服务平台、APP/H5 办事大厅。 基层便民服务站、长者模式、打印友好页。 城市运行中心、部门监管驾驶舱（只读）。
